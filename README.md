## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone [YOUR_GITHUB_REPOSITORY_URL](https://github.com/PariRastogi18/FAIRY-PORTFOLIO)
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and add your EmailJS credentials:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

Replace the placeholder values with your actual EmailJS configuration.

**Note:** These variable names are for Vite projects. If the project uses Create React App, configure the corresponding `REACT_APP_` variables instead.

### 5. Start the Development Server

For Vite:

```bash
npm run dev
```

For Create React App:

```bash
npm start
```

Open the local URL displayed in your terminal to view the website.
